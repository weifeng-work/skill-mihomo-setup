# skill-mihomo-setup

让 AI 助手（智能体）在 **Linux 或 Windows** 上自动部署一套「开箱即用」的
[Mihomo（Clash Meta）](https://github.com/MetaCubeX/mihomo) 代理，全程只要求用户做两件事：
**提供订阅链接（或 YAML）** 和 **点击系统弹出的授权确认框**，其余全部由智能体完成。

## 这是什么

一个 **AI skill**——一份安装给智能体使用的"操作手册 + 现成脚本"。智能体装上后，当你提出
"帮我把这台的代理配好"，它会自动：检测操作系统 → 下载二进制 → 拉取订阅 → 打补丁（节点策略/
TUN/域名嗅探/fake-ip DNS）→ 校验 → 安装为系统服务 → 配置开机自启与每日更新 → 启动，并打开
状态面板给你看效果。零命令行操作、零手写配置。

## 给谁用、什么场景

| 目标用户 | 典型场景 |
|---|---|
| 不熟悉命令行的普通用户 | 拿到一个机场订阅链接，想让整台电脑科学上网 |
| 需要"重装即恢复"的用户 | 换新机器，让智能体几分钟内复刻出一模一样的代理 |
| Windows / Linux 家用机 | TUN 全局模式，浏览器、命令行、应用全部走代理 |
| 想省事的重度用户 | 节点自动优选、订阅每日热更新、随时停止/切换/查状态 |

适合 Docker 之外的**裸机/桌面系统**部署（Debian/Ubuntu 系 Linux 或 Windows 10/11）。

## 使用前提

1. 一台可联网的 **Linux（Debian/Ubuntu 系）** 或 **Windows** 电脑，有管理员/root 权限。
2. **任选其一**的代理来源（缺了下面任何一样都装不起来，智能体会先问你要）：
   - 一个机场 **订阅链接**（`https://.../link?clash=...`，能返回 Clash/Mihomo YAML），或
   - 一份你已有的 **YAML 配置**。
3. 装了支持 skill 的智能体（如 OpenCode / Claude Code 等，按各自要求把 skill 放入对应目录）。
4. 网络能访问 GitHub 或 ghfast.top 镜像（下载 mihomo 二进制），GFW 内实测镜像可用。

## 怎么用：把这句话交给你的智能体

安装 skill 后，对你的智能体说：

> 请帮我安装并部署 mihomo 代理。我需要你机器人式的全自动处理：下载安装最新 mihomo、
> 配置 TUN 全局模式、订阅自动更新，配置好 Web 面板。我提供订阅链接：`你的订阅URL`
> （或：我会把 YAML 配置的路径给你）。凡是需要系统授权弹窗的地方，把鼠标交给我来点确认。

如果尚未安装 skill，先说：

> 请把这个 GitHub 仓库安装成 skill：
> `https://github.com/weifeng-work/skill-mihomo-setup`，
> 然后阅读它的 SKILL.md 并严格按照里面的部署流程来。

部署过程中，当系统弹出「允许代理/新建网络/TUN」之类的授权框时，点"允许"即可，
其余交给智能体。

## 应有的效果

装好之后，你会得到：

- **全局可上网**：TUN 透明代理开启，浏览器、命令行、应用无感走代理。
- **订阅自动更新**：每天定时拉取最新订阅、校验、热加载，节点掉线自动换节点（离网/机场换域名也不怕）。
- **一目了然的状态面板**：浏览器打开 `http://127.0.0.1:8080` 看到当前节点/延迟/重启次数/自启状态，
  一个按钮就能停止代理（临时全直连）、启动、切换路由模式、立即更新订阅。
- **开机自启的服务**：重启电脑后代理和面板自动恢复运行。
- **可复现**：换机器重装，智能体照 SKILL.md 几分钟复刻。

后续想修问题/调优，继续对智能体说"帮我看看代理为什么慢了/连不上了"，它会读这个 skill 自查。

